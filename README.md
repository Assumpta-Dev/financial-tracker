# Personal Finance Tracker

## Description
A full-stack web application that helps users track income and expenses through a simple financial dashboard.

## Technologies
**React, TypeScript, Tailwind CSS, Firebase, Git**

## Project Overview
The Personal Finance Tracker is a web application designed to help users monitor their financial activity. Users can create accounts, record income and expense transactions, and track their spending over time through a dashboard interface.

The application securely stores user data and provides a structured way to manage personal or small-business finances.

## Features
- User account creation and authentication
- Add and manage income and expense transactions
- Dashboard interface for tracking financial activity
- Secure data storage using Firebase
- Responsive and user-friendly interface

## What I Implemented
- User authentication and account management
- Transaction tracking functionality
- Database integration for financial records
- Dashboard interface for displaying financial data
